# v1.0.1 — Update aur Test Data ke bugs fix

Aap ne report kiya tha:
> "Update karne par message aata hai ke next restart pe update ho jayega, magar app
> close karke dobara kholne par koi test data add nahi hua."

Dono cheezein asal bugs thin. Neeche poori tafseel hai.

---

## 1. Asal wajah — do alag bugs the

### Bug A: Test data kabhi install hi nahi ho sakta tha (database)

`lib/db/database_helper.dart` mein:

```dart
return await openDatabase(
  path,
  version: 1,            // ← DB version kabhi bump nahi hua
  onCreate: _onCreate,   // ← saara seed data YAHAN tha
);                       // ← onUpgrade MOJOOD HI NAHI tha
```

`onCreate` sirf **pehli baar** chalta hai jab DB file banti hai. Aap ke phone pe DB
v1.0.0 se pehle se bani hui thi, is liye:

- Naya APK install karo → DB wahi purani khulti hai
- DB version 1 == 1 → SQLite kuch nahi karta
- `onCreate` dobara nahi chalta → **seed data insert hi nahi hota**

Yaani test data sirf tab aata jab aap app ka data clear karte ya app uninstall karke
dobara lagate.

**Fix:**

```dart
static const int _dbVersion = 2;

return await openDatabase(
  path,
  version: _dbVersion,
  onCreate: _onCreate,
  onUpgrade: _onUpgrade,     // ← ab maujood hai
);

Future<void> _onUpgrade(Database db, int oldVersion, int newVersion) async {
  if (oldVersion < 2) {
    await _seedTeachers(db);
    await _seedStudents(db);
  }
}
```

Seeding ko `_seedUsers` / `_seedTeachers` / `_seedStudents` mein nikala gaya, aur har
ek **idempotent** hai (pehle `SELECT COUNT(*)` check karta hai) taake:
- `onCreate` aur `onUpgrade` dono se safely call ho sakein
- Duplicate rows na banein
- **Aap ka pehle se dala hua data mehfooz rahe** — sirf khaali tables seed hoti hain

### Bug B: Update check jhoot bolta tha

`lib/services/update_service.dart` aur `settings_screen.dart` mein:

| # | Masla | Natija |
|---|---|---|
| 1 | `static const _currentVersion = '1.0.0'` — **hardcoded** | 1.0.1 install karne ke baad bhi app khud ko 1.0.0 samajhti. Har check pe "update available" aata rehta, chahe update ho chuka ho |
| 2 | `applyUpdate()` sirf SnackBar dikhata tha | "Update Now" dabane pe kuch hota hi nahi tha |
| 3 | Settings mein "Shorebird OTA updates apply on app restart" aur "Only downloads changed code (small, fast)" likha tha | **Shorebird configured hi nahi** — na `shorebird.yaml`, na koi dependency. Yeh text jhoot tha |
| 4 | `pubspec.yaml` mein `version: 1.0.0+1` tha jabke `version.json` 1.0.1 kehta tha | Naya APK banate bhi version 1.0.0 hi rehta |
| 5 | `_isNewer()` string-split karta tha magar `+build` handle nahi karta tha | `1.0.1+2` jaisi versions pe ghalat compare |

**Fix:**
- Version ab `package_info_plus` se aata hai (asli installed version)
- `pubspec.yaml` → `version: 1.0.1+2`
- "Update Now" ki jagah **"APK Download karein"** — browser mein APK ka page khulta hai
  (`launchUrl`, jo pehle se dependency thi)
- Jhootay Shorebird labels hata diye; ab saaf likha hai ke nayi APK install karni parti hai
- Version compare numeric hai (`1.0.10 > 1.0.9` sahi) aur `+build` ignore hota hai
- GitHub ke version.json pe cache-buster lagaya, warna CDN purana version de sakta tha
- `context.mounted` check add kiya (async gap ke baad context use karna crash de sakta tha)

## 3. Ehem: app khud update NAHI ho sakti

Yeh saaf kar deta hoon kyunke purana UI yehi dawa karta tha:

**Is app mein koi OTA/self-update mechanism nahi hai.** Android pe app khud apni APK
download karke install nahi kar sakti jab tak:
- ya to **Shorebird** set up ho (sirf Dart code patch karta hai — **database seeding
  jaisi cheezein is se theek nahi hotin**, kyunke woh pehle se chal chuki hoti hai),
- ya to **in-app APK download + install** banaya jaye (REQUEST_INSTALL_PACKAGES permission,
  FileProvider, user ko manually "Install" dabana parta hai).

Is liye ab app jhoot nahi bolti — woh saaf kehti hai ke APK download karke install
karni hogi, aur download page khol deti hai.

Agar aap chahte hain ke app ke andar hi download + install ho (ek button, baqi khud),
toh woh bana sakta hoon — `dio` + `open_filex` + FileProvider + permission lagenge.
